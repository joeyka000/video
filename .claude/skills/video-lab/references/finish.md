# 高級質感（finish）

這份管「每一格看起來貴不貴」：曝光、白平衡、高光、黑、膚色、彩度、光暈、顆粒，以及觀眾說不出來、但一看就覺得廉價的小毛病（字在抖、縮圖在閃、漸層一圈一圈）。鏡頭怎麼接看 `story.md`，色票與字型規格看 `craft.md`。

工具：
- `scripts/look.py`：調色與膠片質感（使用者通過的日田 v2、峇里島 v2 整理出來的版本）；`look.py board` 先選 look
- `scripts/finish.py`：逐鏡頭量質感（壓縮後的成片），出 `report.md`、`grade.jpg`、`grade.png`
- `scripts/seekkit.py`：引擎零件，次像素、抗閃爍、抖色、動態模糊、標點擠壓都已內建
- `scripts/finishtest.py`：看不見的精度回歸測試（改過 seekkit／look／finish 之後跑，約 15 秒）
- `scripts/frames.py deliver`：交付壓檔已帶暗部與顆粒保護的 x265 參數

---

## 零、高級感從哪裡來

三層，缺一層就掉一個檔次：
1. **影像本身**：一套 look 貫穿全片；曝光與白平衡先統一再調色；高光有柔肩、不一刀切白；黑乾淨而且每個鏡頭一樣黑；膚色準；彩度節制。
2. **看不見的精度**：字慢慢移動不會一頓一頓、照片緩推不會閃、漸層沒有色階、線條是銳的、快速運動有動態模糊、壓檔後暗部不糊成色塊。
3. **節制**：光暈只在本來就亮的地方，星芒一個畫面最多 4 個，箔光掃一次，顆粒細，暗角輕，特效一支片一個大招（`masters.md`〈零〉：質感來自調色、光、節奏、聲音，不是貼紙字與全幅閃光）。

一看就廉價的訊號（`finish.py` 量得到的標★）：
- ★天空、窗外、臉的高光一刀切白（沒有柔肩）
- ★黑被壓死成一片，或每個鏡頭黑得不一樣（有的灰濛濛、有的死黑）
- ★每個鏡頭白平衡各自為政（手機自動白平衡）
- ★顏色爆掉（最亮的純色連成色塊、紋理沒了）；膚色偏橘、偏洋紅或偏綠
- ★漸層一圈一圈（暗部、天空、scrim、暗角）
- 字慢慢移動時一頓一頓；照片緩推時磚牆、招牌字、樹葉在閃
- 光暈、星芒每個鏡頭都有；顆粒太粗或每格一模一樣；字加粗描邊

## 一、每個鏡頭的處理順序

| 步驟 | 做什麼 | 工具 |
|---|---|---|
| 1 素材修正 | 穩定、降噪、去閃爍（調色前做，雜訊會被調色放大） | `footage.py` |
| 2 統一 | 白平衡往灰世界拉 35%（夕陽、霓虹這種顏色就是主角的畫面 15%）、曝光拉到 mood 的中間調，亮部有上限 | `look.normalize` |
| 3 調色 | 綠往橄欖、降飽和但保護膚色、分離色調（暗部青、亮部暖，皮膚不被推走）、高光柔肩 | `look.color`（內含 `tone`） |
| 4 光 | 高光外暈（halation，紅橘、貼著亮邊）＋泛光（bloom）；點光源才加變形鏡頭光斑 | `look.glow`、`look.anamorphic` |
| 5 臉 | 調完臉中央亮度 > 0.60 就降曝光重調（閃光自拍、逆光提亮會白成一片） | `look.face_safe`（包含 2–4） |
| 6 對齊 | 把這個鏡頭的黑位、白位、中性色對到全片代表鏡頭（不動中間調） | `look.match(img, look.stats(代表鏡頭))` |
| 7 合成 | 字、圖形、callout；字一律 `text_sprite`／`blit`（次像素、預乘 alpha） | `seekkit` |
| 8 膠片 | 顆粒（中間調最明顯、24 格一換）＋暗角；字也吃一點顆粒，才像在畫面裡 | `look.film` |
| 9 輸出 | `to_u8`（預設抖色）→ `frames.py video` → `frames.py deliver` | `seekkit`、`frames.py` |
| 10 量 | 壓檔後的成片再量一次 | `finish.py check` |

順序的理由：先統一再調色，同一個 mood 才會在每個鏡頭長得一樣；光暈在調色之後，才不會被分離色調染色；顆粒最後加，字和實拍才在同一個質地裡；抖色在轉 8-bit 那一刻做才有用。

```python
from look import face_safe, film, match, stats
REF = stats(face_safe(src(V1).at(7.4), 'clean'))          # 全片代表鏡頭（白天、有中性色）
def shot_img(src_frame):
    return match(face_safe(src_frame, 'clean'), REF, 0.7)  # 0.7：對齊七成，保留一點場景本身的差異
def frame(t):
    c = shot_img(...)            # 2–6
    ...                          # 7 字卡
    return to_u8(film(c, t, FPS, grain=0.025))  # 8–9
```

**會搖鏡、會換景的鏡頭，整個鏡頭鎖一組參數**：`face_safe`／`match` 每格都重量一次，搖鏡時畫面內容一變（亮窗→暗室），增益就跟著變，同一張桌子會一格亮一格暗，像手機自動曝光在呼吸（`finishtest.py` F：同一張木桌在 24 格搖鏡裡亮度差 0.169）。改成一個鏡頭量一次：

```python
from look import lock, apply
L = lock(src(V).at(t_rep), 'day', ref=REF, strength=0.7)   # t_rep：這個鏡頭最有代表性的一格（主體清楚、曝光正常）
img = apply(src(V).at(t_src, blend=True), L)               # 全鏡頭同一組白平衡、曝光、臉的降光、黑白位與偏色（差 0.000）
```
手機素材本身已經有自動曝光；鎖參數只是不再疊一層。固定機位、不換景的鏡頭兩種寫法結果一樣。

## 二、Look board：先選 look，再寫引擎

```
python scripts/look.py board a.jpg b.jpg clip.mp4@3.2 ... --moods clean,soft,day,golden,aot,night -o qa/look_board.jpg
```
- 素材挑 5–8 格涵蓋全片的狀況：白天、夜晚、室內、人臉特寫、食物或產品、最重要的那個鏡頭
- 每格格頭有 `finish.py` 的數字：黑位、白位、彩度、高光硬切比例、膚色角度；紅字＝那一格有問題
- 怎麼選：
  1. 先刪掉有紅字的 mood（膚色偏 > 12°、高光硬切）
  2. 剩下的照語氣挑一個（`mv-direction.md`〈三〉的幽默／冷／溫柔三擇一）：溫柔 → soft／golden；冷 → aot／clean；幽默 → clean（形式越正經越好笑）
  3. 全片一個 mood；夜景另外最多一個變體（同一套 teal／warm 方向）
- look board 給使用者看、選定後才寫引擎（跟 `mv-direction.md` 的 treatment 確認點同一個時機）

## 三、Mood 怎麼挑

| mood | 用在 | 個性 | 小心 |
|---|---|---|---|
| clean | 商品、品牌、空間導覽、教學 | 膚色準、幾乎不偏色、柔肩、乾淨的黑 | 太乾淨會像型錄：靠光（halation 0.08）與顆粒救 |
| soft | 生活、美食、親子、溫柔的回憶 | 低對比、黑位抬一點、亮部柔 | 黑位太浮會像霧；暗場景不要用 |
| day | 旅遊白天、戶外 | 自然、微暖、綠色不刺眼 | 正午硬光仍要靠素材本身 |
| golden | 夕陽、溫暖的段落、片尾 | 暖、亮部帶金 | 膚色角容易到 128°，再多就橘 |
| aot | 冷調、史詩感、懸疑 | 低彩度、高對比、暗部青 | 膚色會到 116–118°（偏冷），人臉特寫多的片慎用 |
| night | 夜景、霓虹、煙火 | 不動曝光、光暈強 | 不能套在已經提亮的夜拍人像（look board 實測膚色 115°、彩度過高） |
| bw | 回憶、轉折段落 | 黑白、高對比 | 一支片只用一段 |

## 四、看不見的精度（`seekkit` 已內建，舊寫法要避開）

| 毛病 | 原因 | 現在的做法 | 實測（2026-10） |
|---|---|---|---|
| 字慢慢移動一頓一頓 | 位置四捨五入到整數 px | `blit` 次像素位置＋預乘 alpha；`text_sprite` 兩倍大畫再縮 | 字 3 秒移 24 px：舊版 89 格裡 65 格停住、再一次跳 1 px；新版 0 格停住、誤差 0.00001 px |
| 照片緩推時細節在閃 | `warpAffine` 大比例縮小不做預濾波 | `cover`／`scroll_page` 先用 INTER_AREA 縮到 2^(-n/4) 階，剩下的小縮放才 warp | 5712 px 原圖緩推 1.00→1.06：時間閃爍降 57%，跟兩倍超取樣參考比 PSNR 32.3 → 37.5 dB |
| 漸層一圈一圈 | 8-bit 量化；壓檔把細微差異抹平 | `to_u8` 預設三角抖色＋顆粒 ≥ 0.016（暗場景多的片 0.02–0.024）；`frames.py deliver` 帶 `aq-mode=3:aq-strength=1.2:psy-rdoq=2` | 暗部漸層壓 HEVC 3.8 Mbps 後的色階長度：沒抖色 64 px；顆粒 0.016 用預設參數 15.8 px（x265 把顆粒當雜訊抹平，色階又回來）；加上 deliver 的參數 3.0 px。`-tune grain` 實測無效 |
| 線條糊 | 半解析度畫再放大 | `glow_line` 線芯全解析度、1/16 px 座標 | — |
| 快速運動像幻燈片 | 每格是瞬間 | `mblur(fn, t, fps, n=5)`：快門時間內取子格平均（只包快速段，成本 ×n） | — |
| 慢放跳格、快轉卡 | 取最近的格 | `Src.at(t, blend=True)` 兩格混合 | — |
| 大圖吃記憶體又慢 | 手機原圖 5712 px 轉 float32 約 290 MB | `image(path, max_side=2 × 輸出長邊)` | — |
| 標題的逗號、引號旁邊空一大塊 | 全形標點佔 1 em，「」，連在一起時空白加倍 | `text_sprite` 字級 ≥ 40 自動擠壓連續標點、行首開引號貼齊網格；單獨的標點維持臺灣排版的全形置中；`wrap_text` 避頭尾 | 「質感」，從：365 → 300 px；單獨逗號不變 |

## 五、光與特效的分寸

| 效果 | 量 | 只在 |
|---|---|---|
| halation（高光外暈） | mood 預設；clean 0.08、golden 0.32 | 自動只吃 Y > 0.78 的地方 |
| bloom（泛光） | 0.06–0.24 | 同上 |
| anamorphic（橫向光斑） | 0.3–0.6 | 點光源（路燈、太陽、煙火）；一支片一兩次 |
| glints（四芒星） | ≤ 4 個、會閃 | 本來就亮的反光點（玻璃、金屬、水面）；不要每個鏡頭都有 |
| holo_sweep（彩虹箔光） | k ≤ 0.25、掃一次 | 卡牌、包裝、金屬題材的大招 |
| light_leak（漏光） | screen 0.5–0.7 | 只在轉場；全片同一種轉場語言 |
| 暗角 | 0.25–0.35 | 全片一樣 |
| 顆粒 | 拍攝素材 0.02–0.04；交付至少 0.016（暗場景多 0.02–0.024） | 全片一樣；字也吃 |
| weave（片門晃動） | ≤ 0.5 px | 膠片感的片才用 |

## 六、字的質感（細節規格在 `craft.md`〈二〉）

- 標題粗體、內文常體，全片字型家族 ≤ 2
- 中文大字不加字距；英文小標全大寫時 tracking +0.04–0.08（`text_sprite(..., tracking=0.06)`）
- 標點：臺灣排版全形置中；標題（字級 ≥ 40）自動擠掉連續標點的雙重空白（「」，」「。」」），行首開引號貼齊左網格；標題句尾的句號可以拿掉
- 不描邊、不加粗光暈；需要可讀性時用 `scrim`（漸層壓暗）或 0.35 的柔陰影
- 字小而精緻放下三分之一（`masters.md`〈零〉第 4 條）；巨大字只在空景、只出現一次
- 字的進場用 `rise`／`type_on`（遮罩升起、逐字），不用淡入；移動中的字一律走 `blit`，不要自己 `int()` 位置

## 七、量化門檻（`finish.py` 的 `TH`；改數字時兩邊一起改）

| 項目 | 門檻 | 理由 |
|---|---|---|
| 高光硬切 | Y ≥ 250 的像素 > 0.5%，而且比 235–249 那一段還多 | 有柔肩的高光會在 235–249 留一段過渡；硬切是直接堆在 250 以上 |
| 死黑 | Y ≤ 3 的像素 > 4% | 暗部細節沒了；夜景刻意的在評分表寫明 |
| 黑位跳 | 鏡頭的 Y 第 1 百分位跟全片中位數差 > 14 | 字卡、黑場不參與比較 |
| 偏色 | 近中性色 Lab a／b 跟全片中位數差 > 6 | 跟 `flow.py` 的色溫跳同一個量法 |
| 顏色爆掉 | 高彩度（C* > 40）、同時有通道撞 255 與撞 0、連成 5×5 以上的色塊，佔畫面 > 0.5% | 峇里島 v2 的調色是 0%；同一格彩度拉 1.4 倍出現 0.1–1.5%、1.8 倍 0.7–3.7%。只撞一邊不算（黃色的藍通道本來就接近 0） |
| 彩度 p95 | 不判對錯，只看全片前後一不一致 | 素材本身鮮豔就高：辦公室導覽 19、峇里島卡牌 51 |
| 膚色 | 人臉中央的 Cb／Cr 向量角離 123° > 12° | 示波器膚色線；`craft.md`〈膚色〉同一個目標 |
| 色階 | 平滑漸層區相同灰階連續長度（64 px 區塊的第 90 百分位）> 8 px | 抖色＋顆粒壓檔後約 2–3；明顯色階 ≥ 40 |
| 全片統一 | 黑位標準差 ≤ 6、偏色分散 ≤ 4 | 字卡（有紋理的區塊 < 50%）、黑場、短於 0.5 秒的過場格不算；淡入淡出的黑格不代表鏡頭 |
| 黑邊 | 從邊緣往內、每列中位數 ≤ 2 且第 75 百分位 ≤ 4 | 黑邊裡有字幕、標題也認得出來；夜空有雜訊，中位數到不了 2 |
| 膚色要算進來的臉 | YuNet 信心 ≥ 0.9，臉中央至少 40% 是膚色像素 | 卡牌、海報上的動漫臉、食物不要算（峇里島實測會誤抓到 140° 以上） |

## 八、實測紀錄

環境：4 核心、ffmpeg 6.1、同時有其他渲染在跑。`finish.py check <片> --flow <該片 flow.json>`（剪點用 `flow.py check` 偵測的），每 0.5 秒取一格。

| 片 | 鏡頭 | 要處理 | 黑位標準差 | 偏色分散 | 彩度 p95 | 最嚴重色階 |
|---|---|---|---|---|---|---|
| 峇里島 v1（使用者退件） | 29 | 3 | 5.4 | 3.7 | 51.3 | 6.7 |
| 峇里島 v2 母帶（使用者通過） | 34 | 5 | 4.9 | 2.8 | 52.0 | 11.8 |
| 峇里島 v2 交付檔（舊壓檔參數） | 34 | 6 | 4.9 | 2.8 | 52.0 | 32.6 |
| 峇里島 v2 交付檔（新壓檔參數） | 34 | 4 | 5.2 | 2.7 | 54.4 | 30.7 |
| GodPack 辦公室 v3 | 21 | 5 | 11.3 | 2.6 | 20.5 | 2.0 |
| 進擊 Reels v5 | 69 | 11 | 4.9 | 3.5 | 26.8 | 4.9 |
| 進擊 v7 全片（3 分鐘） | 89 | 9 | 6.2 | 4.5 | 24.2 | 3.4 |
| あのね。Reels | 63 | 19 | 23.7 | 2.8 | 16.6 | 4.1 |

讀法（每一條都是看過標紅的格子才下的結論）：
1. **畫質過關不代表片子過關**：峇里島 v1 的統一度跟 v2 一樣好，退件原因是實拍覆蓋太低（`flow.py`，story.md）。`finish.py` 管的是「看起來貴不貴」，不管「好不好看」
2. **色階是壓檔造成的，不是母帶**：峇里島 v2 片尾收品牌色那 3 秒，母帶 7.8 px → 舊參數交付 32.6 px；換成 `aq-mode=3:psy-rdoq=2` 只降到 30.7。母帶那段沒有顆粒，壓縮器就沒有東西可以保留。同一段 6 秒、同樣 3727 kbps 再比一次：

   | 壓檔前處理 | 色階 |
   |---|---|
   | 什麼都不加 | 38.1 px |
   | `gradfun`（去色階濾鏡） | 26.7 px |
   | `noise=alls=3:allf=t+u`（很淡的動態顆粒，`frames.py deliver --grain 3`） | 12.6 px |
   | 母帶本身 | 9.3 px |

   做法：**平滑漸層（片尾收色、暗場、scrim）在母帶裡就要有顆粒 ≥ 0.016**；舊母帶來不及重渲，交付時加 `--grain 3`。壓完一定用 `finish.py` 量交付檔，不是量母帶
3. **高調（亮）畫面的「黑位跳」多半是內容，不是調色**：辦公室 v3 的 4 個黑位跳（+15–22）都是米色門板特寫和白色座位區，畫面裡本來就沒有黑的東西。判斷法：格子裡有沒有「應該是黑的東西」（頭髮、陰影、門縫）；有才是調色沒統一。片尾黑底品牌卡的死黑 8.3% 是設計
4. **刻意雙風格的片，全片統一門檻改成段落內統一**：あのね。的粉彩漫畫格黑位 55–74、純黑底格 1–3，標準差 23.7 是設計。這種片在評分表寫明「兩種風格各自的黑位範圍」，再檢查同一種風格內的標準差
5. **原作素材混剪（動畫、他人拍的片）偏色分散會偏高**：進擊 v7 4.5，是原作各場景本來的色調；只要求自己拍的實拍段 ≤ 4
6. **高光硬切出現在天空、窗、舞台燈**：進擊 Reels 3 處、峇里島 v1／v2 各 1 處，都是沒過 `tone()` 肩部的原始素材；新片走 `look.py` 管線就不會出現
