# 向大師學：各國導演與動畫 OP 的剪輯手法

用法：接案時先看〈零〉的教訓，再用〈六〉的選擇器挑**一個主語言＋最多一個副語言**，到二～四節讀那位作者的條目，照「我們怎麼做」落地。不要把整份清單的招式全混在一支片裡——大師的共同點是**一套語言貫徹到底**，不是招式多。

每條的格式：**做什麼** → **為什麼有效** → **我們怎麼做**（工具／函式／配方）→ **不要用的時候**。

---

## 零、本 repo 學到的教訓（使用者回饋，優先於下面所有條目）

1. **特效是讓實拍升級，不是取代實拍。** 峇里島 60 秒 v1 被退：巨大漢字蓋住主體、黑白衝擊格整個換掉畫面、整段 3D 舞台（約 18 秒看不到實拍）。v2 改成「實拍永遠是主角」才過。判斷題：把特效關掉，觀眾還看得到原本拍的東西嗎？看不到就是做過頭。
2. **質感來自調色、光、節奏、聲音**：局部對比＋分離色調＋高光暈染、實拍高光處長星芒、很淡的箔光掃過、漏光／甩鏡轉場、落拍輕推鏡（≤ 1.04）、音效設計。不是來自貼紙字、卡通描邊、全幅閃黑白。
3. **卡牌／主題元素貼著實拍做**：例如把那一格畫面本身變成金屬框卡片（背景用同畫面模糊），而不是另做一張設計卡片蓋上去。
4. **字小而精緻，只放下三分之一**，背後墊淡漸層；章節字（DAY 1）用金屬襯線疊在實拍上。巨大字只有在畫面本身是空景、而且只出現一次時才用。
5. **每一招都要能回答「為什麼在這一拍」**：沒有理由的效果刪掉。
6. **花錢的步驟（AI 生成）每一筆先問**，見 SKILL.md〈H〉。
7. **字幕要像設計過的，不像自動字幕。** 峇里島寶可夢片 v1 的歌詞翻譯被說「很醜沒有質感」：粗黑體、每個詞各自升起、詞跟詞之間空隙不一、整條灰色壓暗帶、30 px 的日期標籤。重做後的規格：明體（Noto Serif CJK）一個家族到底；中文翻譯 46 px＋日文原句 24 px 小字在上（字距 0.14）；整句 3 格出現、4 格消失，不做逐字動畫；可讀性靠字底下的柔橢圓壓暗＋貼著筆畫的寬柔陰影，兩者依底下亮度加減；日期用襯線數字＋一條細金線畫出＋字距拉開的小字。零件：`seekkit.caption`，規格：`finish.md`〈六〉。
8. **「動漫風」要的是動畫撮影的質感，不是卡通濾鏡。** 寶可夢峇里島動漫版 v1 被說「不夠有質感，看起來很陽春的動畫」：實拍轉色塊＋描邊、白色集中線、放射色塊、膠囊徽章、遊戲對話框、粗描邊字——每一樣都是廉價動畫特效的特徵。重做的方向：實拍保留照片細節，套動畫撮影調色（天空青藍、暗部藍紫、亮部暖、ブルーム、ディフュージョン）；特效都是「光」（透過光、景深光斑、光束、後光、衝擊波光環），有光暈、有景深、有動態模糊；寶可夢元素做成有體積與光澤的東西（立體打光的球、玻璃質感徽章、毛玻璃面板）；字是柔陰影白字＋金色漸層，不描邊；重特效只放在四個高潮，其他段只有光與空氣。零件：`scripts/animepro.py`，做法：`anime.md`〈四之二〉。

## 一、怎麼判斷一招有沒有學到位

- 學的是**原理**（為什麼有效），不是表面樣子。Edgar Wright 的速剪有效，是因為「每一刀都落在聲音上」，不是因為「很快」。
- 抄構圖可以（致敬），抄角色、Logo、片名字樣不行（見 `anime.md`〈五、授權與分寸〉）。
- 一支片一個「大招」，放在最大的副歌；其他段落只用那套語言的基本功。

## 二、各國導演

### Edgar Wright（英國）— 聲畫同步、速剪插入鏡、甩鏡
- **做什麼**：日常動作（倒咖啡、開門、拿卡）切成 3–6 個極近特寫連剪，每一刀配一個音效；兩個空間用甩鏡（whip pan）接。《Baby Driver》把動作、槍聲、甚至咀嚼都編在歌的節拍上，約 336 秒 220 刀（平均約 1.5 秒一刀）。
- **為什麼有效**：剪點和聲音同時發生，觀眾的大腦把它當成「一個事件」，節奏感來自同步，不是來自快。
- **我們怎麼做**：`editing.md`〈招式表〉的 whip、配方 7；速剪插入鏡用 cuts.csv 每列 2–4 格、剪點吸附 onset（`analyze.py` 的 onsets），每刀在 `audio()` 疊一個短音效（`sfx.swish`／`hit` 的短版）。素材不夠時用同一支影片的不同裁切（`cover(z, cx, cy)`）當不同鏡頭。
- **不要用**：抒情段、回憶段；素材本身是長鏡頭美景時。

### Guy Ritchie（英國）— 定格角色介紹＋名字字卡
- **做什麼**：角色出場時畫面定格、加上名字，《Snatch》用十幾次定格介紹一大群角色；打鬥用定格與變速。源頭是義大利西部片片頭。
- **為什麼有效**：一秒內告訴觀眾「這個人很重要、他叫什麼」，又製造停頓的節奏對比。
- **我們怎麼做**：峇里島 v2 的 `k_fcard`（畫面定格 → 縮成金屬框卡片＋名條）就是這招的卡牌版；純定格版用 `editing.md` 配方 4（tpad 停格）＋下三分之一名字。定格那一格前面加 2 格速度斜坡（快→停）更有力。
- **不要用**：只有一個主角又已經介紹過；情緒段。

### Wes Anderson（美國）— 對稱置中、正上方俯拍、平面甩鏡
- **做什麼**：主體放正中央的對稱構圖；物件用正上方俯拍平鋪；甩鏡時鏡頭保持和主體平行（平面感）。
- **為什麼有效**：形式感強、一眼就是「被設計過的畫面」，讓日常物件變成插畫。
- **我們怎麼做**：食物、卡牌、戰利品的俯拍鏡頭置中裁切（`cover(cx=0.5)`），兩個俯拍之間用水平 whip；色票收成粉彩（`craft.md`〈色票紀律〉）。拍攝建議：請使用者正上方垂直拍一張平鋪（卡、早餐）。
- **不要用**：手持晃動的素材硬裁成對稱會很假；動作場面。

### 王家衛（香港）— 抽格（step printing）、低格率拖影、時間字卡
- **做什麼**：《重慶森林》用約 8–12 fps 拍攝再補格（step printing），主角清楚、周圍人潮拖成殘影，表現時間與孤獨。
- **為什麼有效**：動作被「拖住」，時間感變得主觀，像記憶。
- **我們怎麼做**：ffmpeg `fps=10,tmix=frames=3` 後再升回 30 fps（`anime.md` 實拍 1 的一拍二是近親）；只用在夜景、人潮、回憶段，搭配霓虹偏色與時間戳小字（例如「10.04 19:53」）。
- **不要用**：需要看清楚細節的鏡頭（卡面、食物特寫）。

### 朴贊郁（南韓）— 用畫面裡的東西做轉場
- **做什麼**：《分手的決心》用 wipe、疊影與各種有創意的轉場串起時空，讓兩小時的片像一場流動的夢。
- **為什麼有效**：轉場本身帶意義（角色的心理），不是裝飾。
- **我們怎麼做**：用前一鏡的物件邊緣當擦畫面的遮罩（手、門框、卡片邊緣：`seg.py` 去背遮罩或深度遮罩 `depth()`），新畫面從物件後面露出來；疊影用 0.3–0.5 秒的交叉溶接，只在「兩個時空有關係」時用。
- **不要用**：快節奏副歌（轉場要時間）。

### 新海誠（日本）— 天空是主角、光、比例
- **做什麼**：戲劇化的天空（雲、夕陽、星空）、強烈的光效（鏡頭光暈、光束、金色光暈）、比人物更細的背景、小小的人物襯出尺度；雨與黃昏對應情緒。
- **為什麼有效**：光與天空直接承載情緒，畫面像畫。
- **我們怎麼做**：天空鏡頭加 `cf.streak`／`cf.glint`（光暈與星芒）、高光暈染（`cine()` 的 halation）、雲用快速慢推；黃昏偏橘粉、雨天偏青。人物放小、天空佔 2/3。`anime.md`〈新海誠系〉。
- **不要用**：陰天平光素材硬加光暈會假；室內鏡頭。

### 今敏（日本）— 場景之間的 match cut
- **做什麼**：場景轉換一律有對應：形狀、位置、動作相同的接、精準的構圖對位、兩個時間交錯剪；還有倒帶、跨線、從電視畫面拉出、黑格跳接、物件擦過畫面。《盜夢偵探》開場四分鐘五個夢全部用 match cut 串起來。
- **為什麼有效**：觀眾的眼睛不用重新找主體，轉場變成「同一個東西變身」，空間和時間被摺在一起。
- **我們怎麼做**：選素材時先找形狀／位置相同的畫面配對（杯口→噴泉池→盤子、手拿杯→手拿卡包→手拿信封），主體中心對齊（`cover` 的 cx／cy 讓兩鏡主體落在同一點），剪點落拍、不加轉場效果。cuts.csv 加 `match` 註記哪兩鏡是配對。
- **不要用**：找不到真的相似的畫面時——硬配比沒配更糟。

### 庵野秀明（日本）—《新世紀福音戰士》的明朝體標題卡、極速插入與長停格
- **做什麼**：黑底、極粗明朝體（Matisse EB）的標題卡，字大到被裁切；極短的插入鏡與文字卡快速閃過；另一極端是長時間的靜止畫面。
- **為什麼有效**：字型本身就是情緒（壓迫、緊張），快與靜的極端對比。
- **我們怎麼做**：章節卡用 Noto Serif CJK Bold／Black，壓扁（水平 0.8～0.9），黑底白字，2–6 格閃現（`anime.md` 的 EVA 系、anime-op `evaCard`）；不用 NERV 標誌或 EVA 片名字樣。
- **不要用**：輕鬆可愛的題材（字卡語氣太重）。

### 渡邊信一郎《星際牛仔》OP〈Tank!〉— 剪影、色塊、分割畫面
- **做什麼**：粉、藍、黃、綠的平面色底配黑色人物剪影，自由排版的文字與片名隨爵士樂的銅管與鼓閃現；方塊與矩形把畫面切成格，留位置給工作人員字幕。常被拿來和 Saul Bass 相比，也受 Blue Note 唱片封面（Reid Miles）與普普藝術影響。
- **為什麼有效**：極簡圖形＋強節奏，辨識度高、很「設計」。
- **我們怎麼做**：人物去背（`seg.py`）填成純黑剪影放在單色底上，幾何分割（`k_split` 類的格狀版型），文字落在鼓點。適合片頭與角色介紹段。
- **不要用**：需要看清楚臉或風景的段落。

## 三、動畫 OP 演出家

### 山下清悟 —《鏈鋸人》OP〈KICK BACK〉、《咒術迴戰》第一季 OP
- **做什麼**：〈KICK BACK〉整支是電影致敬（《黑色追緝令》、《康斯坦汀：驅魔神探》、《異世浮生》、《謀殺綠腳趾》、《霸道橫行》、《鬥陣俱樂部》、《德州電鋸殺人狂》等），用觀眾認得的經典構圖演自己的角色。
- **為什麼有效**：熟悉的構圖給觀眾「認出來」的快感，同時把角色放進電影語境。
- **我們怎麼做**：挑 1–2 個大家都認得的經典構圖（例：《黑色追緝令》的並排走路），請使用者照著拍或用 AI 生成；剪輯照原片的鏡位與時長。只用構圖，不用原片畫面。
- **不要用**：觀眾群不熟那些電影時，致敬沒有意義。

### 石浜真史 — SPY×FAMILY 第一季 OP〈ミックスナッツ〉（監督・分鏡）
- **我們學什麼**：以平面設計與圖形轉場串起整支 OP 的做法（看片確認具體招式後再補這條）。

### 湯淺政明 — SPY×FAMILY 第二季 OP（監督）
- **我們學什麼**：流動變形、誇張透視、線條本身在動。實拍做不到變形動畫，但可以學「一個動作貫穿多個畫面」的連續感。

### 斎藤圭一郎 —《孤獨搖滾！》OP〈青春コンプレックス〉（監督・分鏡）
- **做什麼**：乍看作畫不複雜，強在構圖與層次：背景用真實場景，角色疊在上面；轉場是當季最好的之一。
- **為什麼有效**：真實場景給生活感，構圖與轉場給設計感——不靠作畫量也能很強。
- **我們怎麼做**：這正是我們的情況（實拍＋圖形元素）。實拍當背景、圖形與文字分層疊上，用深度（`depth()`）讓元素有前後；每個轉場都設計（match cut、物件擦、色塊推）。

### 動畫 OP 的共通結構（TV 版約 89 秒，可縮成 60 秒 Reels）
| 段落 | 該做的事 | 旅行影片對應 |
|---|---|---|
| 前奏 hook（0–10 秒） | 最強的一個畫面＋標題 logo；或冷開場一句 | 最好看的一鏡＋標題 |
| 主歌 | 角色日常、慢推、角色點名 | 早餐、移動、地點介紹 |
| 預副歌 | 加速、壓抑、剪點變密 | 準備出發、排隊、期待 |
| 副歌 | 大招（作畫高潮）、群像、奔跑、轉身 | 戰利品、最精彩的時刻、變速＋高光 |
| 收尾 | 全員合照＋logo | 合照或總結畫面＋標題 |
常見元素：角色依序橫移點名、360° 旋轉鏡頭、剪影、奔跑、仰望天空、工作人員字幕排在構圖留白處。

## 四、旅行影片創作者

### Sam Kolder — 拍攝時就設計好的轉場
- **做什麼**：招牌是「持續推進的 zoom 轉場」——前一鏡結尾推進、下一鏡開頭接著推進；用縮時分隔地點；大量速度斜坡。關鍵是**拍攝時就為轉場拍**，剪輯只是接起來。
- **我們怎麼做**：給使用者拍攝建議清單（每個地點拍一個「推進結尾」與一個「推進開頭」、一個遮擋鏡頭——手或物件擋住鏡頭）；剪輯時把同方向運動的兩鏡接在拍點、中間 2–4 格加徑向模糊（`radial_blur`）。
- **不要用**：素材都是固定機位時硬做 zoom 轉場會很假。

## 五、手法 → 我們的工具

| 手法 | 程式／配方 |
|---|---|
| 速剪插入、聲畫同步 | cuts.csv 2–4 格一刀、onset 吸附、每刀一個短音效 |
| 甩鏡 whip | `editing.md` 配方 7；`bali60b` 的 `whip` |
| 定格＋名字 | 配方 4 tpad；`k_fcard`（卡片版） |
| 抽格拖影 | `fps=10,tmix=frames=3` 再 `fps=30` |
| 物件擦畫面 | `seg.py` 遮罩或 `depth()` 前景遮罩當 wipe |
| match cut | 配對表＋`cover(cx, cy)` 對齊主體 |
| 光暈、星芒、高光暈染 | `cf.streak`、`cf.glint`、`auto_glints`、`cine()` |
| 明朝體標題卡 | Noto Serif CJK 壓扁、黑底、2–6 格 |
| 剪影色塊 | `seg.py` 遮罩填黑＋單色底＋格狀分割 |
| 箔光（卡牌題材） | `holo_sweep`（淡、只掃一次） |
| 速度斜坡 | `src_time` 的 ramp 關鍵格；快段多格合成動態模糊 |

## 七、交付前追加自檢（和 `craft.md`〈六〉一起答）

1. 主語言是誰？哪幾個鏡頭最能看出來？
2. 把所有特效關掉，主體還看得到嗎？有沒有任何一刻特效蓋過實拍？（〈零〉第 1 條）
3. 大招在哪一拍？全片是不是只有一個？
