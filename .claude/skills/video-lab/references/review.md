# 縮圖總覽評分關卡（正式渲染前必過）

兩道關卡，都要全部 ≥ 8：**縮圖總覽**看「一格好不好看」（本文前半），**剪點**看「兩格之間接得好不好」（〈剪點評分〉）。概念在寫分鏡前先過 `story.md`〈一、3. 概念壓力測試〉。

流程：`frames.py sheet`（seek(t) 引擎）或 `render.py --sheet`／`review.py sheet --video`（試渲片）→ 逐格打分寫進 `<sheet>.review.json` → `review.py gate` → 沒過就修最差的 3 格、重出總覽（round 自動 +1，上一輪存成 `.review.rN.json`）→ 再評 → 全部 ≥ 8 才進 10 秒試渲與全片渲染。

## 抽格怎麼抽
- 引擎寫 `MARKS = [(秒, '標籤'), ...]`：每個段落的代表格、每個大招的峰值格、每張字卡完全進場後的那一格、每個轉場的正中間、片頭第一個有內容的格、片尾 logo 定住的格
- 至少 12 格；60 秒以上的片 24 格以上。轉場和動態問題靜態格看不出來，交給 10 秒試渲

## 1–10 分的錨點
| 分 | 這一格長什麼樣 |
|---|---|
| 10 | 拿去投 Awwwards／得獎作品集也不心虛；有只屬於這個題材的巧思 |
| 9 | 專業品牌片水準，挑不出問題，也有一點個性 |
| **8** | **可以直接發**：沒有錯、層級清楚（一眼知道先看哪裡）、品牌色與字型一致、字落在安全區、實拍沒被蓋掉、高光有柔肩、膚色自然、跟相鄰鏡頭同一套調色；剩下的只是品味層級的改進 |
| 7 | 有一個說得出來的明確問題（字太小或太擠、對齊偏、壓到主體、留白不平衡、截圖切得尷尬） |
| 5–6 | 兩個以上的問題，或一看就是模板（禁用清單裡的東西） |
| 3–4 | 硬傷：字出框或被裁、豆腐字、字壓臉或壓在別的字上、資訊錯（數字、文案、密碼、網址）、捏造的介面或數據 |
| 1–2 | 壞格：黑格、破圖、素材沒載入、錯的鏡頭 |

硬傷直接 ≤ 4，不管其他地方多好看。

## 評分紀律（避免自己給自己放水）
- 每格都要寫 `why`：≥ 8 也要說出具體為什麼及格（「層級清楚、字在乾淨區、標題對齊左網格」），寫不出來就不是 8
- < 8 一定要寫 `fix`：具體到要改哪個參數或哪段程式
- 先找毛病再給分：每格先問「標題、主體、字、邊緣、品牌色」五處各有沒有問題，再對錨點
- 同一個問題在多格出現（例如全片字都太小）每格都扣，修一次全部解決
- 第 4 輪還有 < 8 的格子：停下來把分數表與卡住的原因給使用者看，不要硬拉分數過關
- 交付時附上最後一輪的平均分與最低分

## 禁用清單（老套，出現就是 ≤ 6）
| 禁用 | 為什麼 | 改用 |
|---|---|---|
| 漸層背景＋置中大標題 | 每個 AI 模板都長這樣，觀眾一秒滑走 | 真實畫面（實拍、真截圖、產品本身）當底，標題對齊網格靠一側，用 scrim 壓暗而不是色塊 |
| 全部淡入淡出 | 沒有節奏，等於沒設計 | 遮罩升起（`rise`）、逐字（`type_on`）、線條畫出（`glow_line`）、硬切在拍上；每種進場有它的理由。淡出只留給片尾收進品牌色那一下 |
| 角落裝飾小標（`VOL.01`、`REC ●`、`©2026`、沒意義的座標與編號） | 填空用的假細節 | 字卡要貼著內容、指向畫面裡的東西（callout 線從真實元素出發），或做成有資訊、有系統的標籤（例：辦公室片的 PSA 卡盒標籤＝段落名＋編號，跟品牌概念綁在一起） |
| 假介面、假數據、假 logo | 做產品片最傷信任 | `brand.py` 抓真截圖、真 logo、真文案；數字只用網站上寫的 |
| 霓虹發光、鏡頭光暈、粒子爆炸蓋滿畫面 | 特效蓋掉內容（使用者回饋過） | 特效只做「升級」：光掃過、局部高光、遮罩轉場，上限是看得到下面的實拍 |
| 每段換一種字型、一種轉場 | 沒有系統 | 全片字型家族 ≤ 2、轉場語言一套 |
| 自動字幕感：粗黑體字幕＋整條灰色壓暗帶＋逐詞跳出 | 使用者回饋「很醜沒有質感」（`masters.md`〈零〉第 7 條） | `seekkit.caption`：明體、原文小字＋翻譯、整句 3 格出現、字底下局部柔壓暗；規格見 `finish.md`〈六〉 |

## 常見的 8 分以下原因（對照修法）
- 字壓在素材自己的字上（網站截圖裡的標題、招牌、海報）→ 換取景（`cover` 的 z 與中心）或改放在乾淨區
- 字被裁掉／出框 → 一律用 `fit_text`／`wrap_text` 量寬度，不寫死字級
- 截圖半截（上一個區塊露一條邊）→ 捲動起訖避開區塊邊界
- 版面重心偏、下半空 → 文字塊以塊高計算置中（`H * 0.42–0.46 − 塊高 / 2`）
- 資訊卡沒指到任何東西 → 線的起點用真實元素的座標，並跟著捲動／縮放一起算
- 硬把走動畫面慢放（< 0.7 倍）→ 又糊又重複格：換一段動作本身清楚的素材，不要靠慢放撐秒數
- 倍速 > 1.25 會混格變糊：要看清楚動作的鏡頭（拿鑰匙、按按鈕）壓在 1.25 以下，改用調整入點湊時間
- 說明文字橫過畫面主體（門鎖、產品、臉）→ 改縮放中心（`zoom(img, z, cx, cy)`）把主體推離字卡區，或換入點，不要先想移字
- 段落代表格只拍到過場（門板、牆）→ 入點往後移到空間或人物真正出現的那一秒
- 天空、窗、臉白成一片（高光硬切）→ `look.tone` 的柔肩，或 `face_safe`；`finish.py` 會標「高光硬切」
- 這格的黑或白平衡跟前後鏡頭不一樣 → `look.match(img, REF)`；`finish.py` 會標「黑位跳」「偏色」
- 膚色偏橘、偏洋紅、偏綠 → 換 mood（look board 看膚色角度）或降分離色調；`finish.py` 會標「膚色偏…」

## 剪點評分（`flow.py check` → `cuts.review.json`）

流程：正式渲染前 `python scripts/flow.py check --engine work/engine.py -o qa/flow`（剪點取自 `SHOTS`，只渲每刀前後 7 格）；有試渲或成片時 `flow.py check out/test.mp4 -o qa/flow`（剪點表有就加 `--cuts`）→ 看 `cuts.jpg`（左 A 末格、右 B 首格；紅點＝A 的視線點、青點＝B 的、空心紅圈＝A 的位置畫在 B 上）→ 逐刀把 score／why／fix 填進 `cuts.review.json` → `review.py gate qa/flow/cuts.review.json`。沒過就修最差的 3 刀、重跑 flow.py（round 自動 +1）。規則與門檻在 `story.md`〈四〉〈五〉〈八〉。

| 分 | 這一刀長什麼樣 |
|---|---|
| 10 | 剪點本身是設計：形狀、顏色或動作對位，或聲音和畫面一起轉；看第二次才發現這裡有一刀 |
| 9 | 動作接或視線完全接上（≤ 0.15），景別與方向都對，再多一個呼應（色、形、聲） |
| **8** | **可以直接發**：看不出接縫，或接縫有理由（段落開頭、重拍上）；同一主體景別差兩級以上或換了角度；入點清楚；色溫接得上 |
| 7 | 一個說得出來的問題：段落中間視線跳 > 0.33、同景別同位置、入點糊 3–4 格、方向相反卻沒有理由、明暗跳在段落中間 |
| 5–6 | 兩個以上的問題；或只跳一刀的跳接（不是連跳的風格）、甩鏡兩邊方向相反、明暗和色溫同時跳 |
| 3–4 | 硬傷：動作沒做完就切走、硬切的入點糊 ≥ 5 格、明顯的重複格、同一個鏡頭用兩次（不是首尾呼應） |
| 1–2 | 錯的鏡頭、黑格、不到 6 格又不是刻意的閃切 |

紀律：
- 每一刀先看五件事：視線、方向、動作、光色、景別，再對錨點
- flow.py 的標記只是提示：有標記但刻意的，why 寫出理由可以給 8；沒標記但看起來不順的，照樣扣分（工具量不到主體自己的方向、語意、表演）
- 算數的「刻意」只有四種：段落開頭、重拍上的衝擊、連跳 3 刀以上的風格化跳接、語意需要（衝突、回頭、轉折）；寫不出是哪一種就不是刻意
- 評分集是嚴重度 ≥ 2 的全部剪點（最多 30 刀），不足 8 刀時均勻補抽查；全部剪點要看就加 `--all` 出 `cuts_all.jpg`
- 交付時附剪點的平均分、最低分，以及 report.md 總覽裡的「實拍不到半個畫面的時間」
