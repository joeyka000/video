# 台灣全年節日與行銷檔期（台灣版）

> 農曆節日日期以 lunardate 換算核對過（2026、2027）；國定假日是否放假、補班與連假安排，**一律以行政院人事行政總處當年公告為準**，排程前要再查一次。
> 「約」表示每年依商家或檔期而定的區間，不是固定日期。

## 長期檔期
- 農曆七月（鬼月）：2026/8/13–9/10 前後，部分產業（房產、婚禮、搬家）會避開
- 寒假：約 1 月下旬–2 月中；暑假：約 7 月–8 月
- 學測：約 1 月中下旬；分科測驗：約 7 月中
- 颱風季：7–9 月（停班停課、防颱準備是 Threads 常見熱門話題）
