加「熱點雷達」功能。

1. 建立 edge function `tw-trends`，程式碼完全照下面（不要改寫邏輯）。它抓 Google 搜尋趨勢台灣、Google 新聞台灣、PTT 熱門看板，免金鑰；也能把當下的 Google 熱搜存成一場 A1 掃描。

2. /trends 頁：
- 上方四個分頁：Google 熱搜、Threads 話題、PTT 熱門看板、Google 新聞（新聞可選主題：科技、娛樂、運動、商業、健康、國際、台灣）
- Google 熱搜、PTT、新聞：呼叫 `supabase.functions.invoke('tw-trends', { method: 'GET' })`，以 query 帶 sources、limit、topic、board（invoke 不方便帶 query 時，改用 fetch 到函式網址並帶使用者的 access token）
- Threads 話題：讀資料庫最新一場 A2 掃描（trend_scans kind='A2' 依 scan_date、scan_time 最新）的 threads_topics，依 no 排序，顯示標題、貼文量、摘要；沒有資料時提示「到 Threads 日報匯入」
- 每一筆：排名、標題（Google 熱搜附搜尋量與第一則相關新聞連結；PTT 附人氣或推文數）、兩個按鈕「收進選題庫」（寫入 ideas，source 記來源名稱）與「拿去改寫」（帶標題到 /publish）
- 右上角顯示更新時間與「重新整理」；Google 熱搜分頁另有一個「立即存一場 A1」按鈕：POST `{ action: 'save_a1' }`，成功後提示並可連到 Threads 日報
- PTT 分頁有一個看板輸入框（例：Gossiping、Lifeismoney、Stock），有填就顯示該板最新文章
- 錯誤時顯示哪個來源失敗，其他來源照常顯示
