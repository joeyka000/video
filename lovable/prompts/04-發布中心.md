2. 建立 edge function `ai`，程式碼完全照下面。它有兩個動作：rewrite（改寫成各平台版本）與 classify_terms（幫 A1 熱搜詞補分類）；每次呼叫都會把 token 與費用寫進 ai_usage，超過本月上限會拒絕。

3. /publish 頁：
- 左欄：標題、正文（母稿，多行）、話題標籤（逗號分隔）、平台多選：Instagram、Threads、Facebook、YouTube、TikTok、LINE 官方帳號、Dcard、PTT（key 依序 instagram、threads、facebook、youtube、tiktok、line、dcard、ptt）
- 按「AI 改寫成各平台版本」→ `supabase.functions.invoke('ai', { body: { action: 'rewrite', title, body, tags, platforms } })`，顯示載入狀態；完成後顯示這次花費（cost_usd，美元，小數兩位）
- 右欄：每個選取的平台一張卡片：平台名、字數／上限（Instagram 2200、Threads 500、Facebook 5000、YouTube 5000、TikTok 2200、LINE 500、Dcard 20000、PTT 20000；超過顯示紅色）、可直接編輯的內容、「複製」按鈕；回傳 missing 有值時在該卡片提示重試
